# Vanilla JS: You Might Not Need a Framework

Welcome to the **Vanilla JS — You Might Not Need a Framework** repository! This project demonstrates how to build scalable, component-based applications using pure, modern Vanilla JavaScript (ES6+), without the overhead or dependency of heavy frontend frameworks like React, Vue, or Angular.

---

## 🚀 Project Overview

Modern web development often defaults to complex frameworks, but vanilla JavaScript has evolved significantly. This repository serves as a practical showcase of how to structure an application using native browser features, custom web components, and modular vanilla code.

### ✨ Key Features

* **Zero Dependencies:** Built entirely with native web technologies.
* **Component-Based Architecture:** Modular design using standard JavaScript classes and templates.
* **Lightweight & Fast:** Minimal bundle size and blazing-fast performance.
* **Modern ES6+:** Utilizes modern JavaScript features (Modules, Async/Await, Arrow Functions, etc.).

## 📁 Repository Structure

```text
vanilla-js/
├── components/       # Reusable UI components
```

## 🛠️ Getting Started

### Prerequisites

To run this project locally, you only need a modern web browser and a local development server (such as the Live Server extension in VS Code).

### Installation & Setup

1. **Clone the repository:**
```bash
git clone https://github.com/AlakaSutar02/vanilla-js.git

```


2. **Navigate to the project directory:**
```bash
cd vanilla-js

```


3. **Run the project:**
* Open `index.html` directly in your browser, or
* Use a local development server (recommended for modules and service workers):
```bash
npx serve .
```

### Deploying to GitHub Pages

Publish the repository root. Asset and data URLs are resolved relative to their
files, so they work both at the domain root and under a repository path such as
`/vanilla-js/`.

## 💡 Why Vanilla JS?

* **Deep Understanding:** Working without a framework helps you master core JavaScript concepts and DOM manipulation.
* **Future-Proof:** Standards change slowly compared to third-party framework ecosystems; code written in vanilla JS stands the test of time.
* **Performance:** Eliminating virtual DOM diffing and heavy runtime libraries leads to immediate execution and small payloads.
